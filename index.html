Currently Building / Selected Work

  • ESP32 Digital Lab ↗

    Browser-based electronics laboratory running on an original ESP32. Validated capabilities: 1 Hz–5 MHz frequency counter, 5 MHz signal generator, 4-channel logic analyzer up to 2 MS/s, and UART / I2C / SPI protocol decoding.

  • BL602-Arduino-Core ↗

    Arduino-compatible development workflow for the Bouffalo Lab BL602 RISC-V MCU. Integrates native SDK and FreeRTOS. Supports GPIO, Serial, I2C, Wi-Fi, HTTP, and experimental BLE.

  • ESP32-S3 CH32V003 Programmer ↗

    ESP32-S3 based 1-wire SWIO programmer and debugger for the CH32V003 RISC-V MCU. Supports flash programming with byte-for-byte readback verification on physical hardware.

  • TWS-A2DP-Mode ↗

    Repurposes a TWS earbud as a Bluetooth / A2DP front-end for MCUs without native Bluetooth. Validated on Arduino Uno using a 3-FSK / Goertzel decoding approach.

  • YKM-FC ↗

    ESP32-C3 micro-drone flight controller running compiled Betaflight. Features MPU6050 IMU, custom discrete MOSFET motor drivers, and 816 motors.

# Ishu1519 — Personal Website

Minimal, clean, technical landing page for Ishu1519. Built with pure HTML and CSS with zero external dependencies and frameworks.

## Project Structure

```text
├── index.html       # Main landing page
├── style.css        # Minimalist dark theme & responsive layout
├── .nojekyll        # Bypasses Jekyll processing on GitHub Pages
├── .gitignore       # Git ignore rules
└── README.md        # Documentation
```

## Deployment via GitHub Pages

1. In your GitHub repository settings, navigate to **Settings** > **Pages**.
2. Under **Build and deployment**:
   - **Source**: Deploy from a branch
   - **Branch**: `main` / `root` (`/`)
3. Save changes. GitHub Pages will publish the site at `https://<username>.github.io/<repo-name>/` (or `https://<username>.github.io/` if repository name is `<username>.github.io`).
